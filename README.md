# PipScript

A Fallout-inspired programming language designed for creating text-based RPG quests and scenarios.

## 1. Language Design and Motivation

### What is the purpose of your language?

The purpose of PipScript is to create quests and scenarios for a command-line-style Fallout RPG game.

### What domain or types of problems is it designed for?

PipScript is designed for game development, specifically text-based RPGs. It allows programmers to create quests, character interactions, dialogue, and different outcomes based on player decisions.

### Why did you choose this particular design?

I chose this design because Fallout is something that interests me, and I wanted to work on a project that I enjoy. I also wanted to create something that helps programmers make fun games without having to write complicated code.

### What are the main features and constructs supported by your language?

PipScript will support the following features:

- **QUEST:** Defines a quest or scenario.
- **SPECIAL:** Creates variables such as health, strength, or caps.
- **SAY:** Displays dialogue or messages.
- **SET:** Updates variables during a quest.
- **IF / ELSE:** Allows different outcomes based on conditions.
- **CHOICE:** Allows players to make decisions that affect the quest.
